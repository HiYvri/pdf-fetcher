# pdf-fetcher

pdf-fetcher 是一款 Zotero 插件，通过聚联医疗获取文献的 PDF 原文，并将下载的文件保存到对应文献条目下。

你可以右键选择文献手动获取，也可以开启 **自动获取PDF原文**：添加新文献后，如果 Zotero 没有获取到 PDF，插件会自动向聚联医疗提交查询。

**提交查询不代表立即获得原文。** 插件会在提交后约 7 秒检查一次结果；如果聚联医疗还在查找，需要你稍后右键检查。插件不会在后台定期查询。

## 使用前需要准备什么

- 一个可使用文献传递服务的[聚联医疗机构认证账号](https://jlyl.jlss.vip/jss/#/index)。
- 该账号的 Token（登录令牌），填写方法见下文。
- 使用自动获取功能需要 **Zotero 10.x**。

目前已在 **Zotero 10.0.8 + Chrome Zotero Connector 5.0.217** 环境中试用浏览器保存后的自动获取功能。其他版本和添加方式未逐一实测。

## 1. 安装插件

1. [下载最新版 pdf-fetcher.xpi](https://github.com/HiYvri/pdf-fetcher/releases/latest/download/pdf-fetcher.xpi)。
2. 打开 Zotero，进入 **工具 → 插件**。
3. 在插件管理页面选择 **从文件安装插件**，打开下载的 `.xpi` 文件。
4. 如 Zotero 提示重启，按提示操作。

## 2. 填写 Token

插件不能直接使用浏览器中的登录状态，因此首次使用前需要填写聚联医疗的 Token。

1. 在浏览器中登录[聚联医疗](https://jlyl.jlss.vip)。
2. 打开浏览器开发者工具，进入 **应用（Application）→ 本地存储（Local Storage）**。
3. 选择 `jlyl.jlss.vip` 或 `jlss.vip` 对应的站点，复制名为 `token` 的值，不包含两边的引号。
4. 打开 **Zotero 设置 → pdf-fetcher**，将其粘贴到 **Token** 输入框，点击 **保存设置**。

如果插件提示登录失效，请重新登录网站，复制新的 Token 并保存。Token 属于账号凭证，请勿公开分享。

## 3. 获取 PDF 原文

### 自动获取PDF原文

此功能**默认关闭**。在 **Zotero 设置 → pdf-fetcher** 中勾选 **自动获取PDF原文** 即可启用，取消勾选即可关闭，设置即时生效。部分版本的设置项显示为“自动获取PDF全文”，指的是同一功能。

开启后，以下两种添加方式会触发自动获取：

- 使用浏览器的 **Zotero Connector** 保存文献。
- 使用 Zotero 的 **通过标识符添加** 功能，输入 **DOI 或 PMID** 添加文献。

插件会先等待 Zotero 自己获取 PDF。如果 Zotero 已经取得 PDF，插件不再提交查询；如果确认获取流程结束后仍没有 PDF，插件才向聚联医疗提交查询，并在约 7 秒后检查一次结果。

- **原文已找到：**自动下载 PDF，保存为该文献的附件。
- **仍在查找：**保留 `fetching PDF` 标签，等待你稍后手动检查，操作见下文。

自动获取只针对开启后通过上述方式新增的文献，**不会扫描或补下载已有文献**。RIS/BibTeX 文件导入、同步、手动新建条目和 ISBN 添加不在自动获取范围内。关闭自动获取后，仍可使用右键菜单手动获取。

### 手动获取或检查结果

1. 在 Zotero 中选中文献条目，而不是其下的附件或笔记。
2. 右键选择 **通过聚联医疗获取原文**。
3. 如果该条目尚未提交，插件会提交查询，并在约 7 秒后检查一次。
4. 如果该条目已有 `fetching PDF` 标签，插件会检查之前提交的任务，不重复提交。
5. 查到原文后，插件会下载 PDF 并移除标签；尚未完成时，稍后再次使用同一右键菜单即可。

无论最初是自动还是手动提交，后续都使用这个右键菜单检查结果。已有 PDF 附件的条目会跳过，不重复下载。

## 常见问题

### 为什么过了 7 秒还没有 PDF？

7 秒是首次检查结果的等待时间，不是原文获取所需时间。有些任务需要聚联医疗人工查找。请稍后右键选择 **通过聚联医疗获取原文**，或到聚联医疗网站查看进度。

### fetching PDF 标签是什么意思？

表示插件已提交查询，尚未完成 PDF 导入。它不表示插件正在后台持续下载。请保留该标签，插件需要用它识别已提交的任务。

### 开启自动获取后，为什么某篇文献没有自动提交？

请先检查它是否通过浏览器 Connector 或 DOI/PMID 新增，以及是否已经有 PDF 附件。对于不支持的添加方式，或插件无法确认 Zotero 获取结果的情况，可直接使用右键菜单手动获取。

### 提示“未找到记录”或“任务失败”怎么办？

请到聚联医疗网站查看任务状态。插件目前只检查最近 20 条任务，较早的记录可能不在查询结果中；未找到记录不等于没有提交成功。

## 版本兼容说明

自动获取功能面向 Zotero 10.x。安装包允许的 Zotero 版本范围为 `6.999` 至 `10.*`，但允许安装不代表每个版本都已验证。插件无法使用某个版本所需的自动获取接口时，会跳过对应的自动操作，仍保留右键手动入口。

## 开发与本地构建

以下内容供需要自行构建插件的开发者参考，普通用户直接下载安装包即可。

```bash
npm install
npm run test:unit
npm run build
```

安装包输出位置：

```text
.scaffold/build/pdf-fetcher.xpi
```

插件使用聚联医疗服务，接口地址为 `https://api.jlss.vip`，按 DOI、PMID、标题、URL 的顺序选取查询信息。接口分析记录见 [docs/network-analysis.md](docs/network-analysis.md)。
